# Changelog

## 0.2.0 (unreleased)

- Accept standard implicit-pressed keystroke strings.
- Provide shared J2CL type/callback prerequisites for Swing.

- Add explicit composed-JRE ownership for java.net.

## 0.1.0 - unreleased

- Stock-J2CL browser profile covering 299 retained top-level AWT types and 4714 callable public members, plus reviewed protected/nested and prerequisite contracts.
- Shared desktop/browser showcase with 37 graphics scenarios and complete retained Graphics2D method coverage.
- Attributed text, native font measurement/rasterization, positioned glyphs and documented layout/shaping limits.
- Prepared software fills, bounded image upload reuse and explicit runtime teardown.
- Stable `@webawt//:webawt` consumer target, source archives, checksums, SBOM and external-project packaging validation.

Known limits are recorded in docs/text-rendering-profile.md and docs/extended-api-profile.md. Manual acceptance expansion and SonarQube/source-attributed percentage coverage are deferred by the project owner. Public distribution awaits the recorded provenance review; no published release is implied by this entry.
