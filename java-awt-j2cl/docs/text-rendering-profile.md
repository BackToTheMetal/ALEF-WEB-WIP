# Retained text and rendering profile

Whole strings use browser-native measurement and glyph rasterization. Attributed drawing snapshots runs, preserves the iterator position, honors per-run font, foreground, background, swap-colors, underline and strikethrough, and restores parent graphics state. TextMeasurer and LineBreakMeasurer preserve those runs; supplied break iterators determine line boundaries. Glyph-vector drawing honors per-glyph position and transform for WebAWT's Unicode-based vectors and uses the custom vector outline for other vectors.

The shared DejaVu reference font establishes a 2 logical-pixel JDK error budget for the showcased advance, caret and highlight measurements. Chromium, Firefox and WebKit additionally compare plain glyph painting against native Canvas at 1x/2x. Whole-run browser shaping is available, but WebAWT does not expose native glyph IDs or real font outlines. Vector outlines and layout ink-bound queries remain metric approximations. Justified layouts scale runs. Rendering hints are retained as state; native engines may not implement each Java hint.

Caret navigation protects surrogate pairs and the tested combining-mark/variation-selector/modifier ranges. This is not a complete Unicode grapheme or bidi algorithm. Mixed-direction styled runs and mixed-direction caret/highlight geometry fail explicitly. Replacement glyph attributes, numeric shaping attributes and explicit bidi embeddings also fail explicitly. Complex-script caret geometry, vertical text, full Unicode segmentation, fallback-run line metrics and font-specific typographic feature control are not retained fidelity claims.

Canvas rejects XOR, arbitrary custom Composite, custom Paint for text and the five previously documented destructive text composite rules. BufferedImage supports custom Paint and bounded glyph-coverage composition. Solid zero-width strokes use one logical device pixel after transformation; dashed zero-width strokes and singular-transform hairlines are explicitly unavailable. Software curved fills prepare edges once at 0.125 logical-device-pixel flatness and sample integer logical pixel coordinates; fractional-edge antialiasing parity is not claimed.

Image uploads use a per-canvas content-verified LRU of at most four images / 262144 pixels. Comparing every pixel catches direct DataBuffer array and shared-subimage mutations. Images larger than the cache limit are uploaded without retention. Software paint rasters are bounded to 64x64 tiles, text to 128x128 coverage tiles. The optimized browser performance check requires 50 curved 256x128 software fills within 2 seconds and asserts exact upload/hit/eviction counts. Separate 2-second budgets cover two 512x513 uncached uploads, ten 512x256-to-256x128 software image draws, and twenty layouts of 100 components. These are bounded regression workloads on the Linux Playwright validation host, not device-independent latency guarantees.

WebAwt installs one application root per document. Installing another root uninstalls the previous runtime. WebAwt.uninstall disposes windows, detaches DOM and document listeners, cancels pending scheduler work, clears queued events, focus/drag state, singleton application listeners and image-upload caches. Repeated uninstallation is safe. Loaded fonts and pending font registration remain document-scoped; a disposed consumer ignores late callbacks. Application-owned Java objects remain the application's responsibility.
